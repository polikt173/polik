# Форма — застосунок для тренувань і харчування

Особистий застосунок Polik'а (Артем Полонський) для підрахунку калорій, БЖВ, води, тренувань, ваги, ліків і добавок.
Спілкування з автором — коротко, неформальною українською. Він хоче готовий результат, а не пояснення.
Тема завжди темна. Інтерфейс має бути «живим»: анімації, плавні переходи, нічого не вилазить за межі блоків.

## Дві версії

| Версія | Де | Особливості |
|---|---|---|
| **APK (Android)** | GitHub `polikt173/polik`, гілка `main` | Основна. Працює офлайн, дані тільки на телефоні. ШІ через Gemini (ключ користувача). Є сканер штрих-кодів і системні сповіщення. |
| **Веб-версія в Claude** | Артефакт claude.ai, slug `5e6980fb-ccac-4b74-9dba-f43f7ed0ac3e`, https://claude.ai/artifact/CfBu1TVgW4a6aVRkMMkw7K | Той самий `index.html`. Дані синхронізуються через акаунт Claude (capability `db`), ШІ через `sample` без ключа. Камери, зовнішніх запитів і сповіщень там немає. |

Код один і той самий — `app/src/main/assets/index.html`. Він сам визначає, де запущений:
`window.claude` → версія в Claude, `window.Native` / `window.Mig` → APK.
Артефакт оновлюється тільки з claude.ai (інструменти артефактів). У Claude Code достатньо міняти репозиторій.

## Як випустити нову версію APK

1. Змінити `app/src/main/assets/index.html` (і за потреби Java).
2. Підняти `versionCode` / `versionName` в `app/build.gradle`.
3. У `index.html` оновити підпис версії в Налаштуваннях: рядок `Форма X.Y</div>` і пару перекладу `'Форма X.Y':'Forma X.Y'`.
4. `git push` у `main` → GitHub Actions (`.github/workflows/build.yml`) збирає debug-APK і створює реліз `v<номер запуску>` з файлом `Forma.apk`.
5. Посилання для телефону: `https://github.com/polikt173/polik/releases/download/vN/Forma.apk`. Нова версія ставиться поверх, дані зберігаються.

Збірка: Gradle 8.9, AGP 8.5.2, Java 17, compileSdk/targetSdk 34, minSdk 26, залежність `androidx.webkit:webkit:1.11.0`.
Локально Android SDK може бути недоступний — збирає тільки CI.

## Android-частина

- Сторінка відкривається через `WebViewAssetLoader` за адресою `https://appassets.androidplatform.net/assets/index.html` (потрібен https-origin для камери і CORS).
- **Mig** — міст для одноразового перенесення `localStorage` зі старих версій (v1–v3 працювали з `file://`). При першому запуску вантажиться `migrate.html`, той віддає дані в SharedPreferences, а `index.html` на старті їх забирає.
- **Native** — міст для сторінки:
  - `setReminders(json)` — список `[{key,time:"HH:MM",title,text}]` → `Reminders.save()` → щоденні будильники (exact, якщо дозволено, інакше `setAndAllowWhileIdle`).
  - `notifState()` → `granted` / `denied` / `default`.
  - `requestNotif()` — запит POST_NOTIFICATIONS (Android 13+) або відкриття налаштувань сповіщень.
  - Після зміни дозволу і в `onResume` сторінці надсилається подія `notifchange`.
- Камера: `onPermissionRequest` → runtime-дозвіл CAMERA. `getDefaultVideoPoster` повертає прозорий 1×1, щоб не було сірої заглушки з кнопкою play.
- Кнопка «Назад» викликає `window.forBack()`: спершу закриває шторку, потім повертає на «Сьогодні», потім виходить.

## index.html — як влаштовано

Один файл: `<style>` + `<script>` в одному блоці `{ ... }`. Рендер через шаблонні рядки, події делеговані через `data-*` атрибути (один обробник `click`, `input`, `change`).
Будь-який текст з даних виводиться через `esc()`.

### Дані

- Стан `S = {profile, custom, weights, meds, rem, days}`.
  - `days['YYYY-MM-DD'] = {food:[], ex:[], water:<склянки>, mt:{'<medId>@HH:MM':1}}`.
  - Запис їжі: `{id, m:'b|l|d|s', n, g, k, p, f, c, fb, sg, sl, l?}`, де `g` — грами (або мл, якщо `l:1`), `fb` клітковина, `sg` цукор, `sl` сіль.
- `localStorage`: `forma.v1` (весь стан), `forma.gkey` (ключ Gemini, тільки на пристрої), `forma.lang` (`uk`/`en`), `forma.gmodel` (остання робоча модель Gemini).
- У версії Claude: колекція `data/users/<uid>`, документи `main` (profile, custom, weights, meds, rem) і `d-YYYY-MM-DD` (food, ex, water, mt). Запис через `touch(key)` → `flush()` з дебаунсом, по одному запису на документ.

### Розрахунки

- BMR за Міффліном–Сан Жеором × коефіцієнт активності (1.2–1.9) × ціль (схуднути 0.82, тримати 1, набрати 1.1). Можна задати свою норму ккал.
- Білки 1.6 г/кг (тримати) або 2 г/кг; жири 0.9 г/кг; вуглеводи — решта.
- Клітковина 30 г (ч) / 25 г (ж); цукор до 90 г на 2000 ккал; сіль до 5 г.
- Вода: ціль у склянках × 250 мл. Рідина = склянки води + напої з `l:1`, крім алкоголю (регулярка `ALC`).
- Спалені на тренуванні ккал НЕ додаються до норми (активність уже в коефіцієнті). Оцінка: MET 4 × 3.5 × вага / 200 × хв.

### База продуктів

- `FOODS` — масив `[uk, en, ккал, Б, Ж, В, вага_шт, назва_шт]` на 100 г / 100 мл.
- `MORE` — фастфуд і страви з тех карт кафе (Гірос ТАЛ, Гірос в піті/булці, Гірос хот-дог, бургер, рол, Цезар, круасани), формат `[..., fb, sg, sl]`. Тех карти пораховані за інгредієнтами; соус узято як часниковий на майонезній основі (~320 ккал/100 г) — це припущення.
- `GEO` — мережа «Грузинський хліб» (назви з префіксом `Грузинський хліб · `). Офіційних калорій мережа не публікує: ваги з меню на Glovo, калорії оцінені за типовими рецептами.
- `EXN` — клітковина/цукор/сіль для `FOODS` за назвою. `DRINKS` — що рахувати в мл.
- Варіанти приготування: варене / смажене на олії / на маслі / запечене / тушковане / на пару.
- Пошук: спершу точні слова (укр і англ назви), якщо порожньо — за основами слів. Префікс назви ранжується вище.

### ШІ

- `getAI()` → у Claude `claude.use('sample')`, в APK `gemini()`.
- Gemini: REST `v1beta/models/<m>:generateContent`, заголовок `x-goog-api-key`. Моделі по черзі (`GMODELS`): спершу Flash-Lite з `thinkingLevel:'minimal'`, далі Flash, у кінці 2.5 з `thinkingBudget:0`. Таймаут 15 с на модель. На 404/400/401/403/429/5xx переходить до наступної. Робоча модель запам'ятовується, однакові запити кешуються.
- Ключі Google нового формату `AQ.…` не працюють зі старими моделями — тому список моделей нові.
- Використання ШІ: розбір «що з'їв» у JSON `[{n,g,k,p,f,c,fb,sg,sl,l?}]` і довідка про ліки `{for,how,side,avoid,doctor}`.

### Інше

- Сканер штрих-кодів: ZXing (`decodeFromConstraints`, задня камера) або ручний ввід → Open Food Facts API v2 (`energy-kcal_100g`, `proteins_100g`, `fat_100g`, `carbohydrates_100g`, `fiber_100g`, `sugars_100g`, `salt_100g`, `product_quantity_unit` для мл). Знайдене зберігається в «Мої продукти» з полем `code`. У версії Claude вкладка «Код» схована.
- Мова: словник `UI` (точні рядки), список `PART` (регулярки для рядків з числами) і `MutationObserver`, що перекладає DOM на льоту, коли `LANG==='en'`. Нові рядки інтерфейсу треба додавати в `UI`.
- Плавні анімації: `A(key, value)` повертає попереднє значення, елементи рендеряться зі старим значенням і `data-w` / `data-o` / `data-y`, а після рендеру їм ставиться нове — CSS-переходи анімують. При зміні вкладки — keyframes (`.anim`).
- Конфеті і вібрація при виконанні норми білка, води, клітковини, після збереження тренування і коли прийнято всі ліки за день.

## Вкладки

- **Сьогодні:** привітання за часом доби, серія днів (вогник), кнопка профілю, перемикач днів, три кільця (ккал, білки, вода), смуги БЖВ і клітковини/цукру/солі, склянка води з хвилями, прийоми їжі з кольоровими іконками, тренування, порада дня.
- **Треня:** статистика за тиждень, шаблони-картки (Full Body, груди+трицепс, спина+біцепс, ноги+плечі, вдома, кардіо), «повторити останнє», підходи з підказкою «минулого разу», рекорди, історія.
- **«+» по центру:** додавання їжі в прийом за часом доби. Вкладки шторки: Пошук / Своє / ШІ / Код.
- **Ліки:** список на сьогодні з галочками, мої ліки й добавки (тип, доза як призначено, кілька часів, зв'язок з їжею), готові добавки з довідкою, довідка ШІ для ліків, нагадування (їжа, вода, ліки) з перемикачами. Програма НЕ підказує дози ліків, скрізь є попередження «не медична порада».
- **Прогрес:** графік ваги, калорії за 7 днів, середні значення.
- **Профіль** (кнопка вгорі): стать, вік, зріст, вага, активність, ціль, норма. Звідти шестерня → **Налаштування**: мова, ключ Gemini, своя норма ккал і води, мої продукти, синхронізація, стерти дані (з підтвердженням).

## Як тестувати

- Синтаксис: витягнути `<script>` з `index.html` і `node --check`.
- Інтерфейс: Playwright + Chrome headless, вікно 360×780 (вузький телефон). Перевіряти, що жоден елемент `#view` не виходить за ширину екрана.
- Gemini і Open Food Facts мокати через `page.route`. Мости Android мокати через `add_init_script` (`window.Native = {...}`).
- Камеру в headless: `--use-fake-ui-for-media-stream --use-fake-device-for-media-stream`.

## Відомі обмеження і що можна доробити

- Калорії страв без етикетки — усереднені; сіль у домашніх стравах розрахована на звичайне підсолювання.
- Записи, додані до v8, не мають клітковини/цукру/солі (рахуються як 0).
- Довідки до готових добавок (`MPRESETS`) тільки українською.
- Сповіщення і камера на реальному телефоні не перевірялись автоматично. На Xiaomi/Samsung може знадобитися вимкнути економію батареї для програми.
- Дані APK не синхронізуються з веб-версією в Claude (різні сховища).
- Ключ Gemini, який автор колись вставив у чат, варто перевипустити (у коді чи репозиторії ключів немає).
