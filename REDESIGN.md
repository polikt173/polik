# Forma 2.5 — redesign preview

- New graphite/mint adaptive launcher icon.
- Eight theme palettes with nutrient, water and chart tokens; themed cards, buttons, tabs and workout icons.
- Exercise-specific vector icons in workout templates, editor, history and records.
- Restrict WebView navigation and camera permissions; preserve local data and file picker.
- Preview branch builds an APK artifact without publishing a public release.

Manual verification: install over a compatible build or test on a separate device; verify backup/restore, old-origin migration, camera, Gemini, all themes, reminders and workout editing. Debug signing may differ between CI runs; back up before uninstalling. Key encryption, full refactoring, release signing, automated calculation tests and cloud sync are not included.
